# Guide de jeu — Infernal House 3DS

Ce guide explique **comment jouer à Infernal House 3DS**, sans révéler la solution des énigmes. Il part du principe que le jeu est déjà installé et que vous arrivez à l'écran titre.

Pour l'installation du fichier `.cia` ou `.3dsx`, reportez-vous au [README du projet](../README.md).

> **À savoir avant de commencer**
>
> Une partie dure au maximum **60 minutes**. Vous pouvez sauvegarder à tout moment pendant l'exploration avec le bouton **START** (voir [Sauvegarder et reprendre une partie](#10-sauvegarder-et-reprendre-une-partie)). Quitter le jeu sans sauvegarder fait perdre la progression depuis la dernière sauvegarde.
>
> Certaines mauvaises décisions peuvent également être fatales. *Infernal House* est un jeu d'exploration et d'expérimentation : observez, essayez, et ne soyez pas surpris si une idée apparemment brillante se révèle finalement assez mauvaise.

## 1. L'écran titre

![Ecran titre](title.png "Ecran titre")

L'écran titre propose les choix suivants :

- **Langue** : passe à la langue suivante. Le changement est immédiat.
- **Continuer** : reprend la partie sauvegardée. Ce choix n'apparaît que si une sauvegarde existe.
- **Introduction** : raconte les événements qui précèdent le jeu. Il est vivement conseillé de la regarder au moins une fois.
- **Nouvelle partie** : commence une nouvelle partie. **Attention : la sauvegarde existante est alors effacée.**
- **Commandes** : affiche un rappel des commandes principales.
- **Crédits** : affiche les crédits du jeu original et du remake.

Vous pouvez vous déplacer dans le menu avec **haut/bas** sur la croix directionnelle ou le stick circulaire, puis valider avec **A**.

Vous pouvez également toucher directement une option sur l'écran tactile.

Dans les pages **Commandes** et **Crédits**, appuyez sur **A**, **B** ou touchez l'écran pour revenir au menu.

### Pendant l'introduction

L'introduction se déroule automatiquement.

- **A** permet d'accélérer la lecture : si du texte est encore en train de s'afficher, il est affiché immédiatement et la séquence continue. Sur une pause, **A** permet de poursuivre.
- **B** abandonne l'introduction et revient à l'écran titre.

L'introduction n'est pas comptée dans les 60 minutes de la partie.

## 2. Les deux écrans

![Interface du jeu](game.png "Interface du jeu")

La 3DS est utilisée comme une petite console d'aventure à deux étages :

- **l'écran du bas** représente la pièce dans laquelle vous vous trouvez. C'est ici que vous touchez les meubles, objets et éléments du décor ;
- **l'écran du haut** contient toutes les informations utiles : inventaire, objet sélectionné, cible actuelle, sorties disponibles et temps restant.


### L'inventaire

![Inventaire](inventory.png "Inventaire")

Les objets que vous ramassez apparaissent dans l'inventaire, en haut de l'écran.

Un cadre indique l'objet actuellement sélectionné. Son nom est également affiché dans la zone **Objet**.

Utilisez la **croix directionnelle** pour parcourir l'inventaire :

- gauche/droite sélectionne l'objet précédent ou suivant ;
- haut/bas permet de passer d'une ligne à l'autre lorsque l'inventaire contient suffisamment d'objets.

### La cible

Lorsque vous touchez un élément interactif dans une pièce, celui-ci devient votre **cible**. Son nom apparaît dans la zone **Cible** de l'écran supérieur.

C'est important lorsque vous voulez utiliser un objet : le jeu doit savoir **quel objet de votre inventaire** vous voulez utiliser et **sur quoi** vous voulez l'utiliser.

### Les directions

Les flèches situées à droite de l'écran supérieur indiquent les directions dans lesquelles vous pouvez actuellement vous déplacer.

Elles peuvent pointer vers le nord, le sud, l'est, l'ouest ou une direction diagonale.

![Directions](directions.png "Directions")

Si une flèche n'est pas affichée, vous ne pouvez pas aller dans cette direction pour le moment. Certaines actions peuvent toutefois ouvrir de nouveaux passages.

### Le chronomètre

Le compteur en haut de l'écran indique le temps restant. Une nouvelle partie commence avec **60 minutes**.

![Chronomètre](timer.png "Chronomètre")

Le temps continue de s'écouler pendant que vous explorez, lisez les messages, examinez vos objets ou résolvez les mini-jeux.

En revanche, le temps passé dans le menu HOME, dans le menu START ou lorsque la console est en veille n'est pas décompté.

Lorsque le compteur atteint zéro, la partie est terminée.

## 3. Se déplacer dans la maison

Utilisez le **stick circulaire** dans la direction où vous souhaitez aller.

Le jeu reconnaît huit directions : haut, bas, gauche, droite et les quatre diagonales.

Une impulsion sur le stick correspond à **un déplacement**. Maintenir le stick dans une direction ne vous fera donc pas traverser plusieurs pièces d'un seul coup : relâchez-le avant le déplacement suivant.

Regardez les flèches de direction sur l'écran supérieur si vous ne savez pas quelles sorties sont disponibles.

## 4. Observer et agir sur le décor

L'écran tactile est le cœur du jeu.

Touchez un meuble, un objet ou un détail du décor pour interagir avec lui.

Le fonctionnement général est volontairement simple :

1.  **Touchez une première fois** un élément pour le sélectionner et, lorsqu'il possède une description, l'examiner.
2.  Fermez le message avec **A**, **B** ou en touchant l'écran.
3.  **Touchez à nouveau le même élément** pour agir dessus : ouvrir une porte, déplacer quelque chose, fouiller, ramasser un objet, etc.

Certains éléments n'ont pas de texte d'examen. Dans ce cas, leur action peut se produire dès le premier toucher.

Il n'existe donc pas de bouton séparé « Prendre » ou « Ouvrir » : lorsque l'action est possible, elle se fait simplement en touchant l'élément concerné.

Essentiellement, la logique à retenir pour explorer toute la maison est :

**regarder → agir → regarder ce qui a changé → agir à nouveau.**


## 5. Utiliser les objets de l'inventaire

Pour utiliser un objet sur quelque chose dans la pièce :

1.  touchez d'abord l'élément du décor concerné afin qu'il devienne la **Cible** ;
2.  avec la **croix directionnelle**, choisissez l'objet voulu dans l'inventaire ;
3.  appuyez sur **A**.

L'écran supérieur vous permet de vérifier les deux informations avant d'appuyer sur A :

- **Objet** = ce que vous allez utiliser ;
- **Cible** = l'endroit ou l'objet sur lequel vous allez l'utiliser.

![Cible](target.png "Exemple de cible et objet")

Si la combinaison n'a pas de sens, le jeu vous l'indique. Vous pouvez alors essayer autre chose.

Certains objets ont une action qui leur est propre et peuvent être utilisés directement avec **A** ; le jeu s'en charge automatiquement.

Un objet utilisé pour résoudre une énigme peut parfois disparaître de l'inventaire. C'est normal : cela signifie généralement qu'il a été placé ou consommé.

## 6. Examiner un objet de l'inventaire

Sélectionnez un objet avec la croix directionnelle puis appuyez sur **X**.

Lorsqu'un objet possède quelque chose à examiner, le haut de l'écran affiche alors sa description, son illustration détaillée ou les informations qu'il contient.

C'est particulièrement important pour les papiers, livres et autres objets susceptibles de contenir un indice.

Pour fermer l'examen et revenir à l'inventaire, appuyez sur **X** ou **B**.

Tous les objets n'ont pas forcément une vue détaillée. Si **X** ne montre rien de particulier, ce n'est pas un problème.

## 7. Les commandes en résumé

| Commande                 | Action                                    |
|--------------------------|-------------------------------------------|
| **Stick circulaire**     | Se déplacer entre les pièces              |
| **Écran tactile**        | Examiner le décor et agir dessus          |
| **Croix directionnelle** | Choisir un objet dans l'inventaire        |
| **A**                    | Utiliser l'objet sélectionné sur la cible |
| **X**                    | Examiner l'objet sélectionné              |
| **B**                    | Fermer / annuler / revenir en arrière     |
| **START**                | Ouvrir le menu : Retour, Sauvegarder, Quitter |

## 8. Les mini-jeux

Certaines énigmes ouvrent un écran interactif particulier. Dans ce cas, les commandes normales de déplacement sont temporairement remplacées par celles du mini-jeu.

La plupart se jouent directement avec l'écran tactile. **B** permet généralement de quitter le mini-jeu et de revenir dans la pièce.

Le chronomètre de la partie continue pendant ces séquences.

### Exemple: le jeu de mémoire

Mettez l'appareil en marche, observez la séquence de couleurs, puis reproduisez-la en touchant les couleurs dans le même ordre.

La séquence devient progressivement plus longue. Une erreur relance le défi.

Appuyez sur **B** ou utilisez l'interrupteur d'arrêt pour quitter.

## 9. Messages, images et écrans d'information

Lorsqu'un message apparaît en bas de l'écran, vous pouvez le fermer avec **A**, **B** ou un toucher sur l'écran tactile.

Certaines actions affichent une image plutôt qu'un texte. Elle se ferme de la même manière.

Pendant l'examen détaillé d'un **objet de l'inventaire**, utilisez en revanche **X** ou **B** pour revenir au jeu.

## 10. Sauvegarder et reprendre une partie

### Le menu START

Appuyez sur **START** pendant la partie pour ouvrir le menu. Il propose trois choix :

- **Retour** : ferme le menu et reprend la partie ;
- **Sauvegarder** : enregistre votre progression ;
- **Quitter** : quitte le jeu.

Choisissez une option avec **haut/bas** puis validez avec **A**, ou touchez-la directement sur l'écran tactile. **B** ou **START** referment le menu.

Le chronomètre est en pause tant que le menu est ouvert.

### Sauvegarder

Choisissez **Sauvegarder** dans le menu START. Le message **« Sauvegardé avec succès »** confirme que tout s'est bien passé.

**Sauvegarder** n'apparaît pas dans le menu pendant un mini-jeu ou une séquence animée. Terminez ou quittez d'abord le mini-jeu, puis appuyez de nouveau sur START.

### Reprendre une partie

Sur l'écran titre, choisissez **Continuer**. Vous retrouvez la partie exactement où vous l'aviez sauvegardée, et le message **« Partie chargée avec succès »** s'affiche.

### Quitter

**Quitter** ferme immédiatement le jeu, **sans sauvegarder et sans confirmation**. Pensez à sauvegarder juste avant.

### Quelques conseils

- Sauvegardez régulièrement, et surtout **avant de tenter une action qui vous semble risquée**.
- Le temps restant est sauvegardé lui aussi : une partie sauvegardée avec 2 minutes restantes reprendra avec 2 minutes restantes.
- Pour reprendre votre partie, choisissez toujours **Continuer**. **Nouvelle partie** efface la sauvegarde dès que vous la choisissez.

## 11. Mourir et recommencer

La maison n'est pas totalement inoffensive.

Certaines actions peuvent provoquer la mort du détective. Le temps peut également arriver à zéro.

Après la séquence de fin de partie, le jeu revient à l'écran titre. Deux possibilités :

- **Continuer** reprend depuis votre dernière sauvegarde, si vous en avez une ;
- **Nouvelle partie** recommence depuis le début : l'état de la maison, l'inventaire et le chronomètre repartent de zéro, et la sauvegarde est effacée.

## 12. Quelques conseils sans révéler les énigmes

Si vous êtes bloqué, commencez par vérifier les choses les plus simples :

- regardez les **flèches de direction** : un nouveau passage a peut-être été ouvert ;
- touchez les éléments du décor, puis **retouchez-les** après avoir lu leur description ;
- examinez avec **X** les objets qui semblent contenir du texte ou un indice ;
- vérifiez la **Cible** avant d'utiliser un objet avec **A** ;
- revenez dans les pièces déjà visitées : une action effectuée ailleurs peut avoir changé quelque chose ;
- observez attentivement les graphismes : un détail du décor peut être interactif ;
- essayez des combinaisons raisonnables. Le jeu est justement conçu pour réagir à vos actions.

Et surtout : ne supposez pas qu'un objet n'est là que pour décorer. Dans une maison comme celle-ci, c'est une hypothèse dangereuse.
